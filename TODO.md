# Список правок

Правки, які попросив власник і які ще не зроблено.


## Зроблено

- [x] Падіння каменів повільніше на 30%.
- [x] Керування не блокується під час падіння й анімацій.
- [x] Злиття в бустер без уламків; уламки кольору каменя.
- [x] Легкий відскок після падіння.
- [x] Назва гри: «Сяйво камень».

- [x] Живий фон: одне небо на всю гру, шість станів (нічне небо, північне сяйво, місячна ніч, туманність, глибокий космос, світанок), перетворення за 9 с, затемнення під полем 60%, падаючі зорі.
- [x] Уламки за справжньою формою й кольором каменя: ламані скалки, 7 штук, площа 30%, зменшення в падінні 70%, розліт 70%, вага 80%, обертання 90%, спалах у клітинці.
- [x] Коли всі цілі рівня виконано, нові камені більше не з'являються згори.
- [x] Народження бустерів: камені летять дугою з хвостом, пауза з ядром, хвиля, спалах і здригання, поява зі світла, іскри, характер кожного бустера і життя після появи.
