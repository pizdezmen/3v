# Сяйво камень

Фентезі-гра "три в ряд" для Android. Лише ігровий процес: без життів, реклами, покупок і метагри.
Зроблена на Godot 4.4 (GDScript), вертикальна орієнтація.

## Що є в грі

- Обмін сусідніх каменів, каскади, сковзання по діагоналі, поля довільної форми з вирізами (до 9 на 12).
- Бустери: ракета (4 в ряд, чистить ряд або стовпець), бомба (кут або Т), зірка (5 в ряд, забирає колір),
  сюрикен (квадрат 2 на 2, сам летить до цілі). Усі комбінації бустерів між собою.
- Перешкоди: ящик (1 або 2 рейки), лід у два шари, ланцюг (висить на клітинці, камені падають крізь нього, ламають його лише бустери).
- Місяць: не збирається у збіги, не рухається пальцем і не ламається бустерами, лише падає. Коли доходить до нижньої клітинки стовпця, виходить з поля.
- Сяйво під каменями у два рівні: рівень знімається, коли на клітинці прибирають камінь збігом або бустером.
- Цілі: прибрати сяйво, зібрати камені кольору, зламати ящики, розтопити лід, зняти ланцюги, опустити місяці донизу. Ліміт ходів, зірки за запас ходів.
- Перемішування, коли ходів немає; підказка після паузи; фінальний салют із залишку ходів.
- Кампанія з 20 ручних рівнів і нескінченний режим зі згенерованими рівнями.
  Кількість ходів для кожного рівня підбирає бот, який проходить рівень кілька разів.

## Як запустити

1. Встановити [Godot 4.4](https://godotengine.org/download) (звичайну версію, не .NET).
2. Відкрити в ньому файл `project.godot` і натиснути F5.

Мишею можна грати так само, як пальцем: тягнути камінь або натиснути два сусідні.

## Як отримати APK

Після кожного надсилання коду GitHub сам збирає гру (вкладка Actions, робота "Тести і збирання").
Готові файли лежать в артефактах запуску: `syaivo-kameniv-android` (APK для телефона)
і `syaivo-kameniv-windows` (версія для комп'ютера). APK підписаний тестовим ключем: для себе цього досить,
для Google Play потрібен власний ключ і збирання у форматі AAB.

## Будова проєкту

| Шлях | Що там |
| --- | --- |
| `scripts/core/board.gd` | Уся логіка поля без графіки. Кожен хід повертає список кроків для анімації |
| `scripts/core/bot.gd` | Бот, що грає рівні й вимірює складність |
| `scripts/core/level_gen.gd` | Генератор рівнів нескінченного режиму |
| `scripts/game/board_view.gd` | Малює поле і програє кроки: падіння, вибухи, польоти |
| `scripts/game/game.gd` | Ігровий екран: панель "Цілі" і "Ходи", перемога, поразка |
| `scripts/ui/` | Меню, сітка рівнів, вікна, фон |
| `scripts/autoload/` | Збереження прогресу, графіка, звук |
| `levels/*.json` | 20 рівнів кампанії |
| `assets/art/*.svg` | Векторна графіка каменів, бустерів і перешкод |
| `tools/gen_sfx.py` | Синтез звуків (Python, numpy) |
| `tools/calibrate.gd` | Статистика бота для рівнів |
| `tests/run_tests.gd` | Автотести логіки |

## Формат рівня

```json
{ "layout": ["#.....#", "..1.2..", ".i.I.c."], "goals": {"crate": 0, "red": 25}, "moves": 20 }
```

Символи поля: `.` випадковий камінь, `#` порожнє місце, `1` і `2` ящик, `i` лід в один шар, `I` лід у два шари,
`c` ланцюг, `H` і `V` ракета, `B` бомба, `S` зірка, `P` сюрикен, `M` місяць, `r` `g` `b` `y` камінь заданого кольору.
Цілі: `red`, `green`, `blue`, `yellow`, `crate`, `ice`, `chain`, `moon`, `glow`. Сяйво задається окремим полем `glow`: рядки цифр 0, 1, 2 тієї самої форми, що й `layout`. Нуль означає "усе, що є на полі".

## Перевірка

```
godot --headless --import
godot --headless -s tests/run_tests.gd      # автотести логіки
godot --headless -s tools/calibrate.gd      # як бот проходить рівні
godot -- level 12 auto                      # рівень 12 проходить бот (демонстрація)
```
